# Лабораторная работа №2 — вариант 1

## Цель работы

Изучить пакетную передачу данных по последовательному интерфейсу RS-232/COM
и реализовать распознавание кадров между двумя пользовательскими станциями.

В варианте 1 выбирается скорость передачи. Длина
данных 8 бит, чётность None и 1 стоп-бит фиксированы. Каждый символ передаётся сразу
после ввода; Enter передаётся как перевод строки.

## Кадр и алгоритм

Каждый введённый символ передаётся отдельным кадром длиной не более 100 байт:

`Флаг | Данные | Тип | Приоритет | Контроль | Резерв (10 байт)`.

Флаг начала кадра — `450501-1`. Поле данных содержит UTF-8 код одного
введённого символа. Поля «Тип», «Приоритет», «Контроль» и все десять
зарезервированных байтов существуют в каждом кадре и передаются нулевыми.
В будущем они могут соответственно обозначать вид кадра, порядок обработки и
контрольную сумму. После флага применяется классический бит-стаффинг: после
каждых пяти подряд единиц добавляется ноль. Приёмник удаляет эти нули и умеет
собирать кадры из произвольных частей потока COM-порта.

В окне состояния сначала выводятся названия полей, далее — значения последних
кадров до и после стаффинга в двоичном виде. Добавленные нули подчёркнуты;
значения резервных байтов согласно заданию не выводятся.

## Запуск

1. Установите зависимости: `pip install -r requirements.txt`.
2. Запустите `python serial_messenger/main.py`.
3. Программа показывает найденные COM-порты и варианты скорости передачи.
2. После выбора порта и скорости она открывает порт с параметрами выбранная
   скорость / 8 / N / 1. Номер порта блокируется, а скорость можно изменить
   во время работы: соединение будет открыто заново с новым значением.
   Скорость второго устройства не проверяется: приложение сразу готово к обмену.
4. Каждый введённый печатный символ сразу записывается в порт в составе
   отдельного кадра; область состояния обновляется.
5. Фоновый поток считывает входящие байты, распознаёт и декодирует кадры,
   добавляя поле данных в область Output без блокирования интерфейса.
5. При закрытии окна поток останавливается, а порт закрывается.

На обоих концах линии для корректного обмена следует выбрать одинаковую
скорость. Программа не сверяет это значение и не показывает ошибок, связанных
со скоростью; при несовпадении принимающая сторона может увидеть искажённые
символы.

## Параметры COM-порта

| Параметр | Значение |
|---|---|
| Baud rate | 110–115200 (выбирается) |
| Byte size | 8 (фиксировано) |
| Parity | None / N (фиксировано) |
| Stop bits | 1 (фиксировано) |
| Timeout | 0.05 с чтение, 1 с запись |

## Проверка

Запустите два экземпляра `main.py` на концах пары COM-портов. В обоих окнах
выберите одинаковое количество стоп-битов. Текст, набранный в Send now одного
экземпляра, должен появляться посимвольно в Received второго; Activity должен
увеличивать счётчик отправленных символов.
